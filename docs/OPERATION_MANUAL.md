# 轴承首末检系统 V1 操作手册

> 文档版本：V1.0
> 编制日期：2026-09-19
> 适用对象：系统管理员、部门管理员、质量/工艺配置人员、PDA 现场操作人员。

## 1. 系统入口和角色

### 1.1 访问地址

| 场景 | 地址 | 使用对象 |
|---|---|---|
| PC 管理端 | http://服务器IP:8080/pc/ | 管理员、配置人员、质量人员 |
| PDA 现场端 | http://服务器IP:8080/pda/ | 现场操作人员、班组长 |
| 开发环境 PC | http://127.0.0.1:5173/pc/ | 开发/调试人员 |
| 开发环境 PDA | http://127.0.0.1:5174/pda/ | 开发/调试人员 |

### 1.2 内置角色

| 角色 | 典型用途 |
|---|---|
| 超级管理员 | 全系统配置、部门维护、完整数据库备份、部门归档恢复 |
| 管理员 | 本部门基础配置、表单、日志、部门归档和一般管理 |
| 普通用户 | PDA 填报、查看本人历史、废除和恢复本人明细 |

## 2. 首次使用和初始化顺序

建议按以下顺序完成初始化，避免出现产线/班次/表单无法选择的问题：

1. 部门维护：创建需要隔离的部门。
2. 产线配置：先创建根产线，再创建子产线。
3. 班次配置：配置至少一个当前生效的班次计划。
4. 产品维护：创建产品并关联可生产产线。
5. 任务与表单：创建首检、末检、报表或登记表模板。
6. 发布表单版本：草稿版本发布后才能分配给产线。
7. 产线分配：将表单版本分配给一条或多条产线。
8. 用户与权限：创建账号、分配角色和部门。
9. Logo 设置、废除原因：按现场管理要求维护。
10. 备份验证：生成一次完整备份和一次部门归档并确认可下载。

## 3. 登录和退出

### 3.1 PC 管理端登录

1. 打开 PC 地址。
2. 输入账号或工号。
3. 输入密码。
4. 按需勾选记住密码或自动登录。
5. 点击进入系统。

默认管理员账号为 admin，初始密码为 1234。首次部署后应立即在用户与权限页面重置密码。公用电脑不要启用记住密码，因为浏览器会保存登录信息。

### 3.2 PDA 现场端登录

1. 打开 PDA 地址。
2. 扫描或输入工号。
3. 按需打开记住工号。
4. 按需打开自动登录。
5. 点击进入工作台。

PDA 当前按工号登录，不输入密码。账号必须启用、允许 PDA 登录，并且所属部门处于启用状态。建议 PDA 只在工厂内网访问。

### 3.3 退出

PC 端点击右上角退出；PDA 端点击工作台右上角退出。退出会清除登录 Cookie 和前端登录状态。PC 端如果保存过密码，需要在浏览器中清除站点数据或取消保存。

## 4. 关键业务概念

| 概念 | 说明 |
|---|---|
| 部门 | 数据隔离边界。普通用户只能访问本部门数据。 |
| 产线 | 生产或检验工位，最多两级。父产线可级联到子产线。 |
| 班次 | 根据时间段判断当前班次；支持跨零点。 |
| 产品 | 现场检验对象，可关联多条产线。 |
| 模板 | 一类表单定义，例如具体产线的首检模板。 |
| 模板版本 | 模板的可追溯快照。历史填报固定引用当时版本。 |
| 产线分配 | 指定某条产线当前使用哪个已发布版本。 |
| 填报 | 一次提交的主记录，包含业务日期、班次、产线、版本和人员。 |
| 明细 | 一次填报中的一行，可单独废除或恢复。 |
| 字段值 | 明细中的测量值、文本、选项或产品。 |
| 有效 | 当前参与日志、日历和导出的明细。 |
| 已废除 | 保留记录但不参与有效统计；必须填写废除原因。 |
| 已恢复 | 曾废除后又恢复为有效，保留恢复原因和时间。 |
| 已被覆盖 | 同一首末检业务上下文中已有更新记录。 |

## 5. 部门维护

只有超级管理员可以维护部门。

### 5.1 新增部门

1. 打开系统 > 部门维护。
2. 点击新增部门。
3. 输入部门编码，例如 donggang。
4. 输入部门名称，例如 东港分厂。
5. 设置启用状态。
6. 保存。

部门编码用于部门归档、恢复和数据隔离，创建后不能被编辑。建议使用小写英文、数字和下划线。

### 5.2 停用部门

已有人员、产线、表单或填报数据的部门不要删除，应切换为停用。停用后，该部门用户不能继续登录，已有数据仍保留。

### 5.3 删除部门

仅当部门没有任何关联数据时可以删除。系统会检查用户、产线、产品、班次、模板、填报、备份、审计和仪表报文。如果提示已有数据，请停用部门。

## 6. 用户与权限

### 6.1 新增用户

1. 打开系统 > 用户与权限。
2. 点击新增用户。
3. 输入工号、用户名。
4. 选择角色。
5. 超级管理员选择所属部门。
6. 保存。

新增用户默认密码为 123456。账号首次使用后应由管理员重置为现场密码。系统只允许一个启用的超级管理员，不能在页面中创建第二个超级管理员。

### 6.2 查询和筛选用户

可按工号或账号模糊查询，也可按角色筛选。表格显示工号、用户名、部门、角色和状态。

### 6.3 启用和停用用户

点击启用或停用可切换账号状态。不能停用当前登录用户。用户停用后，新登录会被拒绝；已有 JWT 的有效期最长仍为 12 小时，但后续权限检查会因用户状态无效而拒绝。

### 6.4 重置密码

1. 在用户行点击重置密码。
2. 按当前实现，管理员可重置为目标默认密码。
3. 通知用户尽快修改或由管理员再次设置现场密码。

### 6.5 修改角色和部门

拥有权限的管理员可以点击角色/部门修改用户的角色和所属部门。超级管理员角色不能分配给其他用户。普通管理员只能管理本部门用户。

### 6.6 批量导入用户

1. 点击批量导入。
2. 下载 Excel 模板。
3. 按模板填写工号、姓名、角色、部门等列。
4. 上传文件并提交。
5. 检查返回的错误行。

导入用户的默认密码为 123456。建议先导入少量测试数据确认角色和部门列格式，再批量导入正式人员。

## 7. 产线配置

### 7.1 手工新增产线

1. 打开配置 > 产线配置。
2. 点击新增产线。
3. 选择上级产线，留空表示根产线。
4. 输入产线编码和名称。
5. 设置状态。
6. 保存。

产线最多两级。根产线可以包含子产线，子产线不能再创建下级。部门和父产线必须在当前可操作范围内。

### 7.2 批量导入产线

1. 点击下载模板。
2. 填写产线编码、产线名称、上级产线编码、状态。
3. 上传 .xlsx 文件。
4. 查看导入数量和错误行。

上级产线编码可以引用系统已有根产线，也可以引用同一个 Excel 中前面定义的根产线。导入使用事务，数据库写入失败会整体回滚，但行级校验错误会返回给操作人员。

### 7.3 编辑、停用和删除

- 编辑：修改名称、上级关系或状态。
- 停用：产线不再出现在新填报选择中，历史数据保留。
- 删除：仅在没有影响业务数据时使用。已有填报的产线建议停用。

## 8. 班次配置

### 8.1 新建班次计划

1. 打开配置 > 班次配置。
2. 点击新增班次。
3. 输入计划名称。
4. 设置生效时间。
5. 添加一个或多个班次。
6. 设置每个班次的开始时间、结束时间和是否跨零点。
7. 保存。

系统按生效时间选择最新计划。建议在换班规则生效前提前配置，并确认当前时间能匹配到有效班次。

### 8.2 跨零点示例

| 班次 | 开始 | 结束 | 跨零点 |
|---|---|---|---|
| 白班 | 08:00 | 20:00 | 否 |
| 夜班 | 20:00 | 08:00 | 是 |

跨零点班次在次日凌晨填报时，业务日期按班次开始日计算。

### 8.3 修改和删除

修改班次会创建新的替代计划并软删除旧计划，历史填报中的班次快照不受影响。删除只影响后续选择，历史填报仍保留快照。

## 9. 产品维护

1. 打开配置 > 产品维护。
2. 点击新增产品。
3. 输入产品编码和名称。
4. 在关联产线树中勾选可生产该产品的产线。
5. 设置状态。
6. 保存。

勾选父产线时，系统会自动关联其全部子产线。PDA/PC 填报产品字段时，只显示当前产线已关联且启用的产品。产品删除后历史填报中的产品文本仍保留。

## 10. 任务与表单

### 10.1 表单类型

| 类型 | 用途 |
|---|---|
| 首检 | 每班或每次生产开始时的首件确认；重复首检必须填写原因。 |
| 末检 | 生产结束或批次结束时确认。 |
| 报表 | 生产过程中的结构化记录。 |
| 登记表 | 需要按行登记的过程记录。 |

### 10.2 新建模板

1. 打开配置 > 任务与表单。
2. 点击新建模板。
3. 输入模板名称和编码。
4. 选择模板类型。
5. 添加填写项目。
6. 调整字段顺序和属性。
7. 保存模板，系统创建 v1 草稿。

模板编码在部门内唯一。首末检模板保存时建议包含产品字段，用于现场产品确认。

### 10.3 字段类型和配置

| 字段类型 | 可配置项 | 说明 |
|---|---|---|
| 文本 | 必填、默认值 | 填写简短文字 |
| 数字 | 必填、单位、最小值、最大值、多个测量值 | 超限只提示，不阻止提交 |
| 单选 | 必填、选项、默认值 | 从配置选项中选择一个 |
| 多选 | 必填、选项、默认值 | 可保存多个值 |
| 日期时间 | 必填、默认值 | 记录时间 |
| 静态文本 | 内容 | 仅展示说明 |
| 产品 | 必填、默认值 | 从当前产线关联产品中选择 |

常用默认变量：

| 变量 | 含义 |
|---|---|
| 双花括号 current_date | 当前业务日期 |
| 双花括号 current_time | 当前时间 |
| 双花括号 current_shift | 当前班次名称 |
| 双花括号 user_name | 当前用户姓名 |
| 双花括号 user_account | 当前用户工号 |
| 双花括号 line_name | 当前产线名称 |
| 双花括号 line_product | 当前产线关联产品列表 |
| 双花括号 form_name | 表单名称 |
| 双花括号 stage | 首检或末检 |

### 10.4 编辑、发布和回滚

1. 点击编辑已有模板，保存时系统创建新草稿版本。
2. 在版本记录中查看历史版本。
3. 发布草稿后，版本才可用于产线分配。
4. 回滚只是把指定产线的活动版本切回历史版本，不会删除任何版本。
5. 首检模板可复制为末检模板。
6. 首末检成对模板可执行同步，按设计同步字段结构。

### 10.5 删除未使用模板

删除未使用按钮会清理没有被产线分配且没有填报记录的模板。已有历史记录的模板应保留，以免影响追溯。

## 11. 产线分配

1. 打开配置 > 产线分配。
2. 选择模板。
3. 从已发布版本中选择版本。
4. 为产线设置版本。
5. 父产线版本会自动级联到子产线；如果子产线已单独设置，则以子产线设置为准。
6. 点击保存。

如果模板只有草稿，页面会提示先发布。发布最新草稿后，再回到产线分配保存。

## 12. PC 填报

1. 打开执行 > PC 填报。
2. 选择产线。
3. 选择首检、末检、报表或登记表任务。
4. 确认业务日期和班次。
5. 按字段填写值。
6. 数字类字段如果超出上下限，页面会给出提示。
7. 如为重复首检，填写重复首检原因。
8. 报表或登记表可按需增加明细行。
9. 点击提交。

提交后日期和班次会锁定，请确认无误后再提交。需要补录时应按现场制度选择正确业务日期和班次。

## 13. 日志、日历和 Excel 导出

### 13.1 查询日志

1. 打开记录 > 日志与导出。
2. 选择产线。
3. 可按任务/表单、日期范围和填报人筛选。
4. 点击查询。
5. 展开记录查看字段、测量值、单位、填报人、工号、操作时间、上下限异常和状态。

### 13.2 使用日历

日历中绿色表示当天有有效填报，白色表示无填报。点击日期可快速切换到当天记录。

### 13.3 导出 Excel

1. 选择产线和日期范围。
2. 点击导出 Excel。
3. 浏览器下载 Excel 文件。

单次导出日期范围不能超过 31 天。首检和末检按业务日期分工作表，报表和登记表合并到数据工作表。导出只包含有效明细，首末检会保留同一业务上下文中的最新记录。

### 13.4 废除和恢复填报

1. 在日志列表展开目标填报。
2. 找到需要处理的明细。
3. 点击废除或恢复。
4. 选择或填写原因。
5. 确认提交。

废除原因由管理员在废除原因页面维护。恢复必须填写原因，历史页面会显示废除和恢复的原因与时间。

## 14. 数据库备份和恢复

### 14.1 生成完整数据库备份

仅超级管理员可用。

1. 打开系统 > 数据库备份。
2. 确认顶部部门切换为全部部门。
3. 点击生成完整数据库备份。
4. 下载 .dump 文件并复制到异机保存。

完整备份使用 pg_dump custom 格式，不能在页面中上传恢复，应由数据库管理员使用 PostgreSQL 工具恢复。

### 14.2 生成部门归档

1. 在顶部选择需要归档的部门。
2. 打开数据库备份。
3. 点击生成部门归档。
4. 下载 .zip 文件。

部门归档包含该部门配置和业务数据，适合部门迁移、回归测试和灾难恢复演练。

### 14.3 恢复部门归档

仅超级管理员可用。

1. 打开数据库备份。
2. 点击恢复部门 ZIP 备份。
3. 选择本系统生成的 .zip 文件。
4. 核对提示，确认恢复。
5. 等待结果并检查部门、用户、产线和填报数量。

恢复会覆盖 ZIP 中部门编码对应的现有业务数据，整个过程在数据库事务中执行。上传文件最大 100MB。恢复前必须备份当前数据库。

## 15. Logo 和废除原因

### 15.1 Logo 设置

1. 打开系统 > Logo 设置。
2. 上传符合要求的图片。
3. 保存。

Logo 按部门保存。超级管理员切换部门后可分别维护不同部门的 Logo。

### 15.2 废除原因

1. 打开配置 > 废除原因。
2. 添加、删除或调整原因文本。
3. 保存。

现场废除明细时可以从该列表选择原因，也可以按页面逻辑使用其他并填写说明。

## 16. PDA 现场操作

### 16.1 选择产线

1. 登录后在工作台查看当前产线。
2. 点击当前产线区域切换产线。
3. 在列表中选择实际工位。
4. 系统自动加载该产线可填写的表单。

系统会记住上次选择的产线。如果当前账号只授权一条末级产线，系统会自动选择。

### 16.2 填写表单

1. 在工作台选择任务。
2. 确认业务日期和班次。
3. 按字段填写。
4. 产品字段点击后从产品列表选择。
5. 多选字段可选择多个值。
6. 多个测量值字段可逐项填写。
7. 数字超限时页面显示异常提示。
8. 重复首检时填写重复首检原因。
9. 点击保存草稿可临时保存；点击提交会在服务器生成正式记录。

### 16.3 断网和草稿

断网时页面显示离线提示：

- 可以继续编辑当前表单。
- 可以保存到浏览器 IndexedDB 草稿。
- 不能提交、查询历史、废除或恢复。
- 恢复网络后重新进入表单，草稿会自动恢复。

草稿只保存在当前 PDA 浏览器中。不要清理浏览器数据，也不要在公用设备上保存敏感草稿。

### 16.4 我的历史

1. 点击工作台右上角我的历史。
2. 可按全部授权产线或指定产线查询。
3. 向下滚动加载更多记录。
4. 点击记录查看本人明细。
5. 查看有效、已废除、已被覆盖和上下限异常状态。
6. 对本人明细执行废除或恢复。

## 17. 推荐日常作业流程

### 17.1 开班前

1. 管理员确认部门和用户状态。
2. 确认班次计划已生效。
3. 确认产线已分配当前表单版本。
4. 确认产品与产线关联正确。
5. 确认 PDA 网络和登录正常。

### 17.2 首检

1. PDA 选择产线。
2. 选择首检任务。
3. 确认班次和产品。
4. 填写首件测量值。
5. 如有超限，按现场制度处理。
6. 提交并确认成功。
7. 如页面提示重复首检，填写原因后再提交。

### 17.3 过程记录

1. 选择报表或登记表。
2. 按需增加明细行。
3. 填写测量值或过程信息。
4. 提交。
5. 在日志页面核对记录和异常提示。

### 17.4 末检和收班

1. 选择末检任务。
2. 填写末件测量值和结束信息。
3. 提交。
4. 管理员检查日志、日历和异常记录。
5. 按制度生成当日 Excel 或部门归档。

## 19. 常见问题排查

| 现象 | 可能原因 | 处理方法 |
|---|---|---|
| 无法登录 PC | 账号停用、密码错误、角色不允许 PC、部门停用 | 检查用户状态、角色 AllowPC 和部门状态 |
| PDA 提示账号不存在或停用 | 工号错误、账号未启用、角色不允许 PDA | 在用户与权限页面检查账号 |
| 工作台没有表单 | 产线未分配模板、模板未发布、产线停用 | 检查产线分配和版本状态 |
| 提示未配置可用班次 | 没有生效班次计划或时间不匹配 | 新建或调整班次计划 |
| 页面无产品可选 | 产品未关联当前产线或已停用 | 在产品维护中关联产线并启用 |
| 首检提交要求原因 | 同产线、同模板、同日期、同班次已有首检 | 按实际情况填写重复首检原因 |
| Excel 导出按钮不可用 | 未选择产线或没有导出权限 | 先选择产线并检查角色权限 |
| 导出提示范围无效 | 日期超过 31 天或起止日期错误 | 缩小日期范围后重试 |
| 完整备份失败 | pg_dump 路径错误、数据库权限或磁盘空间不足 | 检查 PG_DUMP_PATH、数据库连接和磁盘 |
| 部门恢复失败 | ZIP 不是本系统生成、部门编码冲突、数据引用不完整 | 使用系统下载的 ZIP，先备份并查看错误信息 |
| 8080 端口被占用 | 已有 API 或 cmd/dev 进程运行 | 停止旧进程或修改 HTTP_ADDR |
| PDA 断网不能提交 | 网络中断 | 保存草稿，恢复网络后再提交 |

## 20. 数据安全和操作规范

1. 生产账号一人一号，禁止共用账号。
2. 超级管理员保持唯一，人员变更后及时移交。
3. 公用电脑不启用记住密码。
4. 完成批次后不要随意修改历史班次、表单或产品。
5. 废除和恢复必须写清真实原因。
6. 完整备份必须复制到异机，不能只放在服务器磁盘。
7. 恢复部门归档前必须先做当前数据库备份。
8. 定期检查账号、部门和产线停用情况。
9. PDA 只接入受控内网，不通过公网直接开放。
10. 出现数据异常时先记录时间、产线、表单和用户，再联系系统管理员。

## 21. 术语表

| 术语 | 含义 |
|---|---|
| 业务日期 | 归属班次开始日的日期，不等于自然日时分 |
| 活动版本 | 某条产线当前用于新填报的已发布模板版本 |
| 快照 | 提交时保存的班次和表单上下文，不随配置变化 |
| 软删除 | 标记 deleted_at，不物理删除，保留追溯引用 |
| 部门归档 | 包含部门业务数据的 ZIP 文件，可在系统内恢复 |
| 完整备份 | PostgreSQL custom 格式的 .dump 文件，由 DBA 恢复 |
| 范围权限 | 按授权产线而不是仅按本人判断的修改或废除权限 |
